# Get Involved

Emscripten-forge strives to be a community project. Contributions from individuals and organizations are welcome. Anyone can participate in the decision-making process openly through GitHub.

## As an individual

- **Packaging ideas or requests, questions, bugs**: [open a GitHub issue](https://github.com/emscripten-forge/recipes/issues).
- **New package recipes**: open a [pull request](https://github.com/emscripten-forge/recipes/pulls) following the recipe template. See [Adding packages](../development/adding_packages.md) and [Recipe format](../development/recipe_format.md) for a walkthrough.

## As an organization

Emscripten-forge is sustained by organizational supporters that contribute engineering time, maintenance, and infrastructure. If your organization would like to support the project, reach out via [GitHub](https://github.com/emscripten-forge/recipes/issues).

Current organizational supporters are listed on the [Credits](credits.md#supporters) page.

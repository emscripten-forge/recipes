# Showcase

Projects that build on emscripten-forge packages:

- **[notebook.link](https://notebook.link/)**: a browser-based notebook service that runs Python and other kernels entirely in the browser, using packages from emscripten-forge.
- **[JupyterLite](https://jupyterlite.readthedocs.io/en/stable/)**: a JupyterLab distribution that runs entirely in the browser. Via [jupyterlite-xeus](https://github.com/jupyterlite/xeus), it uses xeus kernels and packages from emscripten-forge.
- **[Mixlab](https://github.com/pymc-labs/mixlab)**: an open-source marketing science studio from PyMC Labs. It runs PyMC-Marketing models with real NUTS inference entirely in the browser, on a Xeus-Python + emscripten-forge runtime.
- **[pyjs-obspy](https://mmesch.com/pyjs-obspy/)**: a worked example of integrating a scientific Python library into a website. It runs [ObsPy](https://obspy.org/) (seismology) in the browser using pyjs and emscripten-forge, with NumPy, SciPy, and Matplotlib available for computation and plotting.

Using emscripten-forge in your project? Open a PR to be listed here.

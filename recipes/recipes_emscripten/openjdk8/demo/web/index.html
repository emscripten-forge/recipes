OpenJDK 8 in the browser

The HotSpot Zero VM and the Java class library compiled to WebAssembly, with AWT/Swing windows drawn by x11.wasm, Java Sound on Web Audio and networking over fetch().

  • Applets

    An AWT applet (animation, images, sound, LiveConnect) and a Swing JApplet, started from ordinary <applet> and <object> tags.

  • Swing application

    A main() program with menus, a table and a dialog, running in a box on the page.

Using it on your own pages

Serve openjdk8.js, openjdk8.wasm, openjdk8-jre.json, openjdk8-jre.data.gz and openjdk8-web.js from one directory and add <script src="openjdk8-web.js"></script> to a page with applets. Needs a browser with WebAssembly JSPI (Chrome/Edge 137 or later).
